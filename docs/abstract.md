# Abstract

Classical polygonal approximation of \(\pi\) produces sequences whose leading error is of order \(N^{-2}\). For the standard inscribed regular polygon half-perimeter

\[
P_N=N\sin\!\left(\frac{\pi}{N}\right),
\]

the error expansion contains only even powers of \(N^{-1}\). This symmetry-induced structure permits exact cross-scale cancellation of the leading term. For any integer \(k>1\), the two-scale N-series operator

\[
\widehat P_N^{(k)}
=
P_{kN}
+
\frac{P_{kN}-P_N}{k^2-1}
\]

satisfies

\[
\widehat P_N^{(k)}
=
\pi+O(N^{-4}).
\]

More generally, multi-scale operators cancel successive even-power terms. The note isolates the geometric source of the even-power hypothesis and records a π-free algebraic chord-trisection verification.
